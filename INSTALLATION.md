## Installation

Download the latest version from the Releases page.

1. Download `JsonLens-x.x.x.zip`
2. Unzip it
3. Drag `JsonLens.app` into Applications
4. Open it

The first launch may be blocked by Gatekeeper because the app is not notarized.

If that happens:

- Right-click JsonLens.app
- Click Open
- Click Open again

> If you are using Apple Silicon, you may need to run `xattr -d com.apple.quarantine JsonLens.app` in Terminal before opening it. Or you can right-click the app and select "Open" from the context menu. Then go to System Preferences > Security & Privacy > General and click "Open Anyway".
